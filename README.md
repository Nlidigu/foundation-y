# Foundation - Internet Terminology Website

This project is part of the Internet Terminology assignment.  
It explains 17 key Internet concepts, each on its own HTML page:

- World Wide Web
- TCP/IP
- Web Browsers
- Web Servers
- URLs
- DNS
- HTTP
- Intranet
- Extranet
- Multitier Architecture
- FTP
- HTML
- Web 1.0
- Web 2.0
- Web 3.0
- Web 4.0

## Features
- Homepage with navigation links to all pages
- Consistent design using CSS
- Images stored in the `images/` folder
- At least 20 commits for version control
